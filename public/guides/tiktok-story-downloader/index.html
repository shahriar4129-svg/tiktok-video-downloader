TikTok story downloader

TikTok stories vanish after 24 hours. If a public story is still live, you can save it as an MP4 file from the browser before it disappears.

Last updated: 24 November 2026 · Reading time: 3 minutes

Open Story mode →

Quick answer

Select Story under Format, paste a direct story media link or a public profile URL, click Download, pick a thumbnail, then close the ad to save the MP4.

How to save a story

  1. Switch to Story mode

    Use the Format buttons in the tool and select Story instead of MP4 or MP3.

  2. Paste a story link

    A direct story media link is the most reliable option. A public profile link also works when TikTok allows the story endpoint on the current network.

  3. Choose and save

    Active stories appear as thumbnails. Pick one, click Download Story, then close the ad to start the save.

What can go wrong

  • No active stories — the story expired, the profile has none, or the endpoint is blocked.
  • Profile link fails — paste the direct story media link instead.
  • Silent file — some stories are image-only or have no audio track.
  • Private story — not supported; only public media can be read.

Respect the 24-hour window

A story that has expired cannot be recovered through a public link. If saving matters, do it while the story is still live, and keep a copy on your own device. Only save stories you own or have permission to keep.

Frequently asked questions

How long are TikTok stories available?

Stories normally disappear after 24 hours. Once expired, the media cannot be recovered from a public link.

Why do I see "No active stories"?

The profile has no story live right now, the story expired, or TikTok is blocking the story endpoint from the current network. Try the direct story media link.

Can I download a private story?

No. Only public story media that the server can read is supported.

What file format is saved?

Stories are saved as MP4 video files, with sound when the source story includes audio.
